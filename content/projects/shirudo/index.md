A BPF-based security platform for Linux, announced by OpenAI and Cisco. It only lets signed loaders load BPF, ships signed micropatches for live mitigations, and proves what is loaded with TPM-signed evidence. I'm one of the maintainers; I brought it up on arm64 and closed root bypasses in its file seal.
